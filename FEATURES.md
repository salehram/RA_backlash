# Feature inventory

**Current release: v0.2.0, experimental. No hardware acceptance completed.**

Status vocabulary: **current** = present in source, not a hardware/accuracy guarantee; **planned** = absent or only partly present (remaining work named explicitly); **research** = investigation, no release commitment. Priority **P0** is a safety/validity release gate, **P1** completes the proposed baseline, **P2** improves usability/integration, **P3** is exploratory. Milestones are proposals, not dates. An em dash in Issue means no public issue has been assigned; do not infer one exists.

This is the authoritative inventory. [ROADMAP.md](ROADMAP.md) references these IDs rather than maintaining a second completion checklist. Stable IDs from the approved plan are retained; BASE IDs organize its numbered baseline work. A current portion of a planned row is not a claim that the whole row is complete.
